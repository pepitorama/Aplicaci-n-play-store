# Checklist de pruebas manuales

## Instalacion / PWA

- [ ] Abrir `http://localhost:4173`.
- [ ] Ver pantalla inicial.
- [ ] Abrir `help.html`.
- [ ] Abrir `privacy.html`.
- [ ] Recargar sin conexion tras visitar la app.

## Juego basico

- [ ] Seleccionar mapa.
- [ ] Seleccionar dificultad.
- [ ] Colocar una torre.
- [ ] Iniciar oleada.
- [ ] Mejorar una torre.
- [ ] Cambiar prioridad con `T`.
- [ ] Vender una torre.

## Sistemas avanzados

- [ ] Activar modo practica.
- [ ] Usar editor de practica.
- [ ] Iniciar desafio diario.
- [ ] Completar una etapa de campana.
- [ ] Comprar investigacion antes de jugar.
- [ ] Ver recursos CPU/RAM/Disco/Red bajar por fugas.

## Guardado

- [ ] Exportar progreso.
- [ ] Importar progreso valido.
- [ ] Intentar importar JSON invalido.
- [ ] Resetear progreso y confirmar backup local.

## Accesibilidad

- [ ] Alto contraste.
- [ ] Modo protanopia/deuteranopia con boton Color.
- [ ] Movimiento reducido.
- [ ] Texto grande.
- [ ] Navegar botones con teclado.

## Fin de partida

- [ ] Ver resumen final.
- [ ] Ver panel "por que perdiste".
- [ ] Confirmar sugerencias automaticas.
- [ ] Confirmar analisis por mapa.
